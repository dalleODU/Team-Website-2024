User Stories

As a Young Adult, I would like to:

    Financial Dashboard

    • Track my financial goals using a personalized dashboard so that I can stay motivated and reduce financial stress.

    What-If Analysis

    • Run a "what-if" analysis on my debt repayment strategies so that I can understand the long-term impact of different financial decisions.
    • Use an algorithmic what-if analysis for simple financial scenarios.
    • Use AI to analyze and generate recommendations based on results of an algorithmic what-if analysis.

    Debt Tracking

    • Create a debt source with source name, amount due, interest rate, term length, and more
    • Edit a debt source with source name, amount due, interest rate, term length, and more
    • Delete a debt source
    • Receive reminders for my payment due dates, so that I never miss a payment and avoid late fees.
    • Add, edit, and delete new debt transaction
    • See all my debt information condensed into one easily-accessible place.
    • Confirm payment of a debt in the app once I paid the actual source in real life.

    AI-Assisted Budgeting

    • Receive AI-driven budgeting suggestions, so that I can optimize my spending and savings based on my financial situation.
    • Create a budget without the use of AI if I don't want to use it.

    Community/Groups

    • Create a group with friends.
    • Join a community/group with other people, my educator, or my personal finance partner.

    Gamification

    • Earn achievements for handling my finances.
    • Stay on track of my finances through goals.

As a Tester, I would like to:

    • Verify that the personal financial dashboard correctly visualizes user spending and debt progress so that the data is accurately represented.
    • Test the Ai-powered recommendations to ensure that they are relevant and helpful for different financial situations.
    • Validate that the “what-if” analysis accurately calculates projected financial outcomes based on different inputs.
    • Simulate various user behaviors to ensure that the app provides appropriate alerts.
